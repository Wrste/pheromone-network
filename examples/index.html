About the built-in N-gram encoder

This demo uses a deterministic character N-gram encoder so it can run offline without a model download or API key.

  • Good for short text, near-duplicates, log templates, and quick prototypes.
  • It compares character fragments, not meaning. Shared phrases can look more similar than they should.
  • It can miss paraphrases that use different words, especially in long or multilingual text.
